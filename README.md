# Pharmacy Visit Forecast System

## 概要
本システムは、調剤薬局向けの来局者予測システムです。

過去の来局者数データをもとにLightGBMで将来の来局者数を予測し、
予測結果から推奨薬剤師人数を算出することで、
薬剤師（ヘルプ要員を含む）の人員配置を支援します。

シンプルな構成とし、人員配置の過不足を一目で確認できるように工夫しました。

また、企業の内部データを取り扱うため、
役職ごとに閲覧可能なデータの範囲や利用できる機能を制限しています。

## 使用技術
- Python 3.13
- Streamlit
- LightGBM
- Pandas
- Plotly
- SQLite
- SQLAlchemy
- pytest
- Git / GitHub

## 主な機能
-　ログイン機能
- ユーザー管理機能(追加、無効化)
- 店舗管理機能(追加、無効化)
- ユーザーアクセス制御
- 店舗ごとのデータ管理
- CSVアップロード、SQLiteへの保存
- LightGBMによる学習
- 来局者数予測
- 推奨薬剤師人数の算出
- 予測結果の保存と表示

## 自動テスト
pytestによる単体テストを実施しています。

予測機能だけでなく、ユーザー管理・店舗管理・認証・などの
主要機能についてもテストを実施しています。

## 手動動作確認
Streamlit上で以下の主要機能を実際に操作し、動作を確認。
- ログイン・認証
- ダッシュボード
- 来局者予測
- 人員配置
- 店舗管理
- ユーザー管理
